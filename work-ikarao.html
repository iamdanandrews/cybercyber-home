The brief

A growing network needs more than a fixed set of logos.

Named subnets and validators need their own identity without fragmenting the network. I developed the visual language, translated it into drawing rules, and delivered the engine and application templates together.

The defining decision

Build the family resemblance into the drawing rules. The team can introduce another name without commissioning another visual direction.

01 / Drawing rulesBittensor

The rule is the identity.

A network adds names faster than a designer can make bespoke logos. Here, the name seeds a drawing engine: the same input and settings return the same mark.

Family resemblance comes from the shared geometry. The engine controls let the team extend that family while keeping density, structure and expression within the system.

02 / RegistersBittensor

One name, two expressions.

Flat line and Circuit use the same seed with different visual densities. The comparison holds the name constant so the effect of that choice can be inspected directly.

That gives the identity room to change with its application. Try both registers in the live engine above, then export the result as an SVG.
